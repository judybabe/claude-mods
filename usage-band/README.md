# usage-band

輸入框上方一列狀態帶：模型膠囊、三個額度、快取倒數、重新整理、檔案入口。

安裝（Claude Code 2.1.275 以上，一步完成）：

```
/plugin install usage-band --marketplace judybabe/claude-mods
```

## 長相

```
 ✳ Fable 5.1 ▾   上下文 ██▌█████ 32%  ·  5 小時 ▉███████ 11% · 3h12m 後重置  ·  本週 ██▊█████ 35%  ·  快取 22:00  ·  ↻ 12 秒前  ·  檔案 ▸
```

- **模型膠囊**：點 ▾ 在狀態列上方展開選單（❯ 目前、其他可用模型、按鍵說明；狀態帶往上長，輸入框不動），點一個就切換、再點膠囊收合，透過 `/model <模型>` 完成；引擎沒接受時膠囊維持原樣。清單在 hooks/model.ts 的 MODELS，目前模型不在清單內時照樣顯示。
- **額度**：上下文、5 小時、本週各一條 8 格進度條，每格再分 1/8，精度約 1.5%；固定「標籤 → 條 → 數字」，數字加粗。
- **三色門檻**：0–59% 藍（正常）、60–84% 黃（注意）、85% 以上紅（危險）並加 ⚠；上下文到危險附「建議 /compact」，5 小時用完顯示「N 後恢復」。
- **重置時間**：寫成「3h12m 後重置」。
- **快取**：prompt cache 剩餘時間 mm:ss 倒數；最後 5 分鐘轉黃並標「即將過期」，過期後灰字「已過期」。
- **↻ 重新整理**：後面寫「多久前更新」。每 60 秒自動重抓；點一下立即重抓，更新中顯示點字旋轉、不可重複觸發，完成後 ✓ 兩秒；超過 5 分鐘沒更新 ↻ 轉黃、額度數字變暗；失敗顯示「⚠ 更新失敗 · ↻ 重試」並保留上次數值。
- **檔案 ▸**：開關 turn-files 的面板，有改動時顯示數量。
- **交接**：上下文超過 70% 出現「交接」按鈕，請 Claude 寫交接檔、清掉對話、用摘要開新對話。

## 窄終端收合

- 120 欄以上：完整。
- 80–119 欄：拿掉進度條與重置說明，只留數字，標籤縮成 5h／週，↻ 只留圖示。
- 80 欄以下：只留模型與警示中的額度（黃或紅），快取、↻、檔案都收起。

每秒更新倒數，每 60 秒重抓額度。
