# usage-band

輸入框上方兩列細帶，隨時看得到模型與額度。

安裝（Claude Code 2.1.275 以上，一步完成）：

```
/plugin install usage-band --marketplace judybabe/claude-mods
```

## 第一列：模型

```
目前模型  [ Fable 5.1 ]  Opus 5.5  Haiku 5.5
```

- 「目前模型」標題後面並排這個帳號能用的模型（Fable 5.1、Opus 5.5、Haiku 5.5，清單在 hooks/model.ts），現在用的那顆是高亮按鈕，其他是淡色文字。
- 點任何一個（或 Tab 聚焦後 Enter）直接切換，透過 `/model <模型>` 完成，和手打指令相同；點目前的那顆不會動作。
- 目前模型不在清單內時（例如自架模型）會排在第一個。
- context 超過 70% 時最右邊出現「交接」按鈕：按下去請 Claude 把目前進度寫成交接檔（檔名用專案名加當下時間），存好、清掉對話，再用交接摘要開新對話。摘要失敗時不動原對話。

## 第二列：額度

```
▰▱▱▱▱ context 18% │ ▰▱▱▱▱ 5h 16% ↻19:00 │ ▱▱▱▱▱ 本週 4% │ ◷ 快取 剩 55 分 │ [ 檔案 ▸ ]
```

- context、五小時、本週各一條五格量表，顏色依用量：50% 以下綠、50 到 80% 黃、超過 80% 紅並加粗。沒有訂閱時額度顯示 — 且不上色。
- 五小時後面的 `↻19:00` 是重置時間。
- `◷` 是 prompt cache 倒數：距上次主要請求還剩幾分鐘有效，最後五分鐘提醒一次，過期後轉紅並說明下一則訊息會重算。
- 「檔案」切換鈕開關 turn-files 的面板（裝了 turn-files 才有內容）。

每 30 秒更新一次。
