# usage-band

輸入框上方一條細帶，隨時看得到：

- 目前模型
- context 用量（百分比，80% 以上轉紅）
- 五小時額度與重置時間、本週額度（沒有訂閱時顯示 —）
- prompt cache 倒數：距上次主要請求還剩幾分鐘有效，最後五分鐘提醒一次，過期後轉紅並說明下一則訊息會重算
- 「檔案」切換鈕：開關 turn-files 的面板（裝了 turn-files 才有內容）

context 超過 70% 時出現「交接」按鈕。按下去會請 Claude 把目前進度寫成交接檔（檔名用專案名加當下時間），存好、清掉對話，再用交接摘要開新對話。摘要失敗時不動原對話。

每 30 秒更新一次。
