# usage-band

輸入框上方一列狀態帶：模型膠囊、三個額度、快取倒數、重新整理、檔案入口。

安裝（Claude Code 2.1.275 以上，一步完成）：

```
/plugin install usage-band --marketplace judybabe/claude-mods
```

## 長相

```
 ✳ Fable 5.1 ▾   上下文 ██▌█████ 32%  ·  5 小時 ▉███████ 11% · 19:00 重置  ·  本週 ██▊█████ 35%  ·  快取 22:00  ·  ↻ 12 秒前  ·  檔案 ▸
```

- **模型膠囊**：點 ▾ 在狀態列上方展開選單，依 Fable／Opus／Sonnet／Haiku 分欄、新版在上，列出這個帳號能用的全部模型（✓ 為目前），點一個就切換、再點膠囊收合；引擎沒接受時膠囊維持原樣。清單在 hooks/model.ts 的 MODELS；清單沒有的新模型只要成為目前模型一次就會被記住，之後一直出現在選單。
- **額度**：上下文、5 小時、本週各一條 8 格進度條，每格再分 1/8，精度約 1.5%；固定「標籤 → 條 → 數字」，數字加粗。
- **三色門檻**：0–59% 藍（正常）、60–84% 黃（注意）、85% 以上紅（危險）並加 ⚠；上下文到危險附「建議 /compact」，5 小時用完顯示「19:00 恢復」。
- **重置時間**：直接寫時間點，今天內「19:00 重置」，跨日「10/25 14:00 重置」。
- **快取**：prompt cache 剩餘時間 mm:ss 倒數（主對話每送出一次請求重新計時 1 小時）；最後 5 分鐘轉黃並標「即將過期」，過期後灰字「已過期」；切換模型、`/clear`、壓縮後快取已失效，改顯示 —，等下一次請求再倒數。
- **↻ 重新整理**：後面寫「多久前更新」。每 60 秒自動重讀；點一下會先送一則極小的 Haiku 請求（1 個 token）讓伺服器回報最新額度再讀，更新中顯示點字旋轉、不可重複觸發，完成後 ✓ 兩秒；超過 5 分鐘沒更新 ↻ 轉黃、額度數字變暗；失敗顯示「⚠ 更新失敗 · ↻ 重試」並保留上次數值。
- **檔案 ▸**：開關 turn-files 的面板，有改動時顯示數量。
- **交接**：上下文超過 70% 出現「交接」按鈕（Claude 回覆中時改成灰字，等回完才能按）。按下後請 Claude 為**整個工作階段**寫交接摘要（五個標題）；只有這則請求開啟的那一輪才算數。回覆含標題才會存到 `~/.claude/handoffs/<專案>-<日期時間>.md`，並在檔尾自動附上從工作階段完整紀錄整理出的「改過的所有檔案」，接著清掉對話、用摘要開新對話。中斷、空白或缺標題時不存檔也不清空；「交接中… 取消」可隨時取消。

## 窄終端收合

依整列實際佔的欄寬（中文算兩欄）挑第一個放得下的版面，永遠不換行：

1. 完整：進度條＋重置時間＋多久前更新。
2. 拿掉重置時間與「多久前」。
3. 拿掉進度條，標籤縮成 5h／週，只留數字。
4. 只留模型與警示中（黃或紅）的額度，快取、↻、檔案收起。
5. 再拿掉「建議 /compact」與交接按鈕。

每秒更新倒數，每 60 秒重抓額度。
